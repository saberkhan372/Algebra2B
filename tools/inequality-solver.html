Inequality Solver
⚠ Multiply or divide by a negative? Flip the symbol.
PICK A PROBLEM
THE ONE KEY RULE
When you multiply or divide both sides by a negative — flip the inequality symbol.

−3x < 12
÷(−3) → flip!
x > −4
OPEN vs CLOSED
> or < → open circle ○ (value not included)
≥ or ≤ → closed circle ● (value included)

Arrow direction matches the symbol — but only when the variable is on the left.
💡 VARIABLE ON THE LEFT
Always end with x on the left side. Then the arrow on the number line points the same way as the symbol:
x > 3 → arrow points right
x < −1 → arrow points left
