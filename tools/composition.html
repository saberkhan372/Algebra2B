HOW TO USE
  1. Pick f and g from the dropdowns.
  2. Type an x value — watch it flow through.
  3. Switch between f∘g and g∘f.
  4. Click "show both orders" to compare.
NOTATION
f ∘ g means "f after g" — g runs first.
(f ∘ g)(x) = f(g(x))

Read inside-out: evaluate g(x) first, then plug that answer into f.

Order matters! Usually f(g(x)) ≠ g(f(x)).
👀 TRY THIS
Q1. Set f = 2x, g = x + 3. Compute f∘g and g∘f at x = 4. Are they the same?
Q2. Can you find f and g where f∘g = g∘f? (Hint: try f = 2x and g = 3x.)
Q3. Set g = √x. What inputs are valid? What happens when you try x = −4?
DOMAIN WARNING
The domain of f∘g is restricted to x-values where g(x) is in the domain of f.

Example: if f = √x and g = x − 5, then f∘g = √(x−5) only works for x ≥ 5.
