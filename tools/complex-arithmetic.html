THE KEY RULES
i = √(−1)
i² = −1 ← the big one
i³ = −i
i⁴ = 1
ADD / SUBTRACT
Group like terms:
(a+bi)+(c+di)
= (a+c) + (b+d)i
Real parts together. Imaginary parts together.
MULTIPLY (FOIL)
(a+bi)(c+di)
= ac + adi + bci + bdi²
= ac + adi + bci − bd
= (ac−bd) + (ad+bc)i
Substitute i²=−1 then combine.
CONJUGATES
(a+bi)(a−bi) = a²+b²
The imaginary parts cancel! This is used for dividing complex numbers.
