CUBIC vs PARABOLA
Parabola vertex: the graph bounces. It's the minimum or maximum — the graph never crosses below/above it.

Cubic inflection: the graph passes straight through. It's where bending switches direction (concave up → concave down). Not a max or min.
√x DOMAIN
You can't square-root a negative number (in the reals). So y = a√(x−h) + k only exists for x ≥ h.

The graph has a hard start point at (h, k) — unlike a parabola which is smooth on both sides.
