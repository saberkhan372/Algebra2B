Quadratic Forms Explorer
One parabola, three forms. Slide the vertex — watch them all stay in sync.
STANDARD
y = x²
reveals: y-intercept
VERTEX
y = x²
reveals: vertex & direction
FACTORED
y = x²
reveals: x-intercepts (zeros)
◎ D = 0 — one repeated root at x = 0 (vertex sits on x-axis)
WHAT EACH FORM REVEALS
STANDARD y-intercept = c (read it directly)
y = ax² + bx + c
VERTEX vertex = (h, k) — no calculation
y = a(x − h)² + k
FACTORED zeros = r₁ and r₂ (set y = 0)
y = a(x − r₁)(x − r₂)
All three describe the same parabola — different disguises, same curve.
CONVERSION SHORTCUTS
Vertex → Standard:
b = −2ah
c = ah² + k
Standard → Vertex:
h = −b / (2a)
k = c − b² / (4a)
Discriminant — a shortcut in vertex form:
D = b² − 4ac
  = −4ak
Zeros (when D ≥ 0):
r = h ± √(−k/a)
HOW TO USE
  1. Slide h and k — move the vertex.
  2. Watch all three forms change together.
  3. Drag k below zero — the factored form appears.
  4. Read the banner — it tracks the discriminant.
👀 TRY THIS
Q1. Set h = 3, k = 0. Standard shows x² − 6x + 9. Factored shows (x − 3)². Are those the same? Try expanding both.
Q2. Set k = 4 (vertex above x-axis). Why does the factored strip say "no real factors"? What does D tell you?
Q3. Set a = −1, h = 2, k = −3. Which form shows the range fastest? Confirm it matches the range chip.
