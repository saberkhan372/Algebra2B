PARENT:
WHY DOES h SHIFT THE "WRONG" WAY?
The key question: what x makes the inside equal zero?
f(x − h) has inside = 0 when x = h. That's where the vertex lands.
h = 3: write (x − 3) = 0 → x = 3 → shifts right.
h = −2: write (x + 2) = 0 → x = −2 → shifts left.
Subtraction in the formula = shift in the positive direction. Always.

THE GENERAL FORMULA
y = a · f(b(x − h)) + k
a — vertical stretch/compress, flip over x-axis
b — horizontal stretch/compress, flip over y-axis (inside!)
h — shift left/right (− means right!)
k — shift up/down
HOW TO USE
  1. Pick a parent function up top.
  2. Move one slider at a time.
  3. Read the yellow box — it tells you what changed and why.
  4. Toggle the gray dashed parent to compare.
TRANSFORMATION ORDER (like PEMDAS)
① h — inside the function → left/right
② a — out front → stretch / reflect
③ k — added at the end → up/down
