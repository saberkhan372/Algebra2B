Transformations Explorer
One formula, every function family. See exactly what a, b, h, and k do.
y = f(x)
Move a slider — this box explains what it does.
PARENT:
1 1 0 0
THE GENERAL FORMULA
y = a · f(b(x − h)) + k
a — vertical stretch/compress, flip over x-axis
b — horizontal stretch/compress, flip over y-axis (inside!)
h — shift left/right (− means right!)
k — shift up/down
HOW TO USE
  1. Pick a parent function up top.
  2. Move one slider at a time.
  3. Read the yellow box — it tells you what changed and why.
  4. Toggle the gray dashed parent to compare.
👀 TRY THIS
Q1. On x², set b = 2. Does the parabola get wider or narrower? Now set a = 2 instead. Same result?
Q2. Set h = 3 on any function. Does it shift left or right? Why does (x − 3) move right?
Q3. Set a = −1 on |x|. What happens? Now switch to x². Is it symmetric? Why/why not?
