Distance · Rate · Time Trainer
Draw a picture → define variables → fill in D = R × T → write equations → solve.
THE GOLDEN FORMULA
D = R × T
Distance = Rate × Time
One row per traveler. Same trip means same time. Same distance means same D.
SETUP STRATEGY
① Draw a picture — label what moves where.
② Define variables — name the unknowns.
③ Fill in the table — D, R, T for each row.
④ Write equations — one per row.
⑤ Solve — elimination usually works best.
WITH/AGAINST PATTERN
Plane/wind or boat/current:
with → add speeds (P + W)
against → subtract (P − W)
Same distance each way → set D equal and divide to find R.
MR. K SAYS
Always draw a picture first. Label which direction each person/vehicle is moving. If you can't draw it, you won't be able to write the equation.
