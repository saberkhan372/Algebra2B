THE TWO CASES
Target appears once:
Clear denominators → move everything else away → isolate.

Target appears multiple times:
Collect all target terms on one side → factor the target out → divide by the group.
⚠ WATCH OUT
After factoring out the target, you divide by the entire group — not just one term.

ax + bx = c
x(a + b) = c
x = c / (a + b) ✓
x = c/a + b ✗
