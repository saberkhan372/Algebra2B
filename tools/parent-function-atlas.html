Parent Function Atlas
Five function families. Domain, range, zeros, asymptotes — all update live.
y = x²
FAMILY:
GENERAL FORM  (Phase 1: b = 1)
y = a · f(x − h) + k
a — vertical stretch / flip
h — left/right shift (subtract = right!)
k — up/down shift
WHAT THE CHIPS MEAN
Domain — valid x-values
Range — possible y-values
Zeros — where y = 0 (x-intercepts)
y-int — value when x = 0
Asymptote — line graph approaches ∞ or never reaches
Special point — vertex, start pt, etc.
HOW TO USE
  1. Pick a function family.
  2. Slide a, h, k and watch the chips update.
  3. Compare colored curve to the gray parent.
  4. Dashed gold lines are asymptotes.
👀 TRY THIS
Q1. On 2ˣ, set k = −4. A zero appears — where is it? Why is the answer h + log₂(4)?
Q2. On 1/x, set h = 2, k = 1. Read both asymptote chips. Where does the zero land?
Q3. On √x, slide h rightward. Watch the domain chip. Why can't you have x-values to the left of h?
