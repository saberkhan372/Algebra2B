HOW TO USE
  1. Each row is one piece of the function.
  2. Click ≡ / ⌒ to switch a piece between linear and parabola.
  3. Linear: set slope m and intercept b. Parabola: set a, h, k (vertex form).
  4. ( ) = open · [ ] = closed endpoint.
  5. Drag the x slider — the active piece lights up.
👀 TRY THIS
Q1. Drag x to the boundary (x = 0). Which piece gets x = 0? Change the endpoint — does the graph change?
Q2. Make a function with a jump discontinuity — the pieces don't meet. What does that look like?
Q3. Can you build a function that is continuous — pieces connect perfectly? What equation has to match at the boundary?
KEY IDEAS
Open ( ): endpoint excluded (hollow dot)
Closed [ ]: endpoint included (filled dot)
Continuous: pieces connect with no gap or jump
Undefined: x falls in no piece's domain
Domain: all x where at least one piece applies
⚠ Vertex outside interval: only part of the parabola shows — plug in the boundary x-values to find the endpoints
