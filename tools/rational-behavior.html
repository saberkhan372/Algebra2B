Horizontal Asymptote Rules
deg N < deg D
→  y = 0
deg N = deg D
→  y = leading ratio
deg N = deg D + 1
→  slant asymptote
deg N > deg D + 1
→  no HA (grows ∞)
HOW IT WORKS
N → factor goes in numerator.
D → factor goes in denominator.
Both N & D → the factor cancels — that's a hole!
Only D → it's a V.A.
Try This
1. Toggle (x+2) into both N and D. What appears — a zero or a hole?
2. Make deg(N) = deg(D). Where does the curve level off?
3. Make deg(N) = deg(D) + 1. Does the curve go up or down forever?
4. Change the leading coeff to −1. What moves — asymptotes or the curve?
