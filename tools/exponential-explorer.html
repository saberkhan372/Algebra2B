Exponential Explorer
Asymptote drawn first. Then the curve. Two strategic points show you where to start.
f(x) =
a 1 stretch / flip b 2 base (growth/decay) h 0 horiz shift k 0 asymptote y = k
An exponential has the variable in the exponent.
If the variable is the base (like x²), it's a polynomial — not exponential.
CLASSROOM STRATEGY
  1. Draw the asymptote first.
  2. Plug in x = h → exponent = 0 → y = a + k.
  3. Plug in x = h + 1 → exponent = 1 → y = ab + k.
  4. Sketch the curve through those two points.
THE FORM
f(x) = a · bx − h + k
a = stretch/flip  ·  b = base
h = horiz shift  ·  k = asymptote
BASE TELLS THE STORY
b > 1: growth (curve goes up right)
0 < b < 1: decay (curve goes down right)
b = 1: constant (not exponential!)
Negative a flips the curve over the asymptote.
👀 TRY THIS
Q1. Slide k to 3. Where does the asymptote move? Does the curve ever cross it?
Q2. Load the decay preset. What happens to the anchor points?
Q3. Set a = −1, b = 2. Which direction does the curve grow now?
