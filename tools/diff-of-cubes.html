Difference of Cubes
The formulas for a³±b³, with examples and a checker. Keep this tab open during homework.
2³ = 8 3³ = 27 4³ = 64 5³ = 125
DIFFERENCE OF CUBES
a³ − b³
= (a − b)(a² + ab + b²)
Note: the trinomial in the second factor is not factorable.
SUM OF CUBES
a³ + b³
= (a + b)(a² − ab + b²)
Note: same structure, just the signs flip.

WORKED EXAMPLES
x³ − 8
= x³ − 2³  ·  a = x, b = 2
= (x − 2)(x² + 2x + 4)
27 + x³
= 3³ + x³  ·  a = 3, b = x
= (3 + x)(9 − 3x + x²)
8x³ − 125
= (2x)³ − 5³  ·  a = 2x, b = 5
= (2x − 5)(4x² + 10x + 25)
64 + 27y³
= 4³ + (3y)³  ·  a = 4, b = 3y
= (4 + 3y)(16 − 12y + 9y²)
