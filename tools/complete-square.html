THE METHOD
For x² + bx + c:
① Take b, divide by 2, square it → (b/2)²
② Add and subtract (b/2)²
③ Factor the perfect square trinomial
④ Simplify the constant

📐 WHERE DID THE FORMULA COME FROM? ▸ show
Complete the square on ax² + bx + c = 0:
ax² + bx + c = 0
start
x² + (b/a)x = −c/a
÷a, move c
x² + (b/a)x + b²/(4a²) = (b²−4ac)/(4a²)
add (b/2a)²
(x + b/(2a))² = (b²−4ac)/(4a²)
factor ←
x + b/(2a) = ±√(b²−4ac) / (2a)
take √
x = (−b ± √(b²−4ac)) / 2a
completing the square — with a, b, c!
WHY IT WORKS
(x + p)² = x² + 2px + p²
So if you see x² + bx, the missing piece is (b/2)². Add it — then subtract it to keep the equation balanced.
