sin ↔ cos
Same wave shape. cos is just sin shifted left by a quarter-period:
cos(x) = sin(x + π/2)
Try switching between sin and cos — only the phase changes.
Try This
1. Set b = 2. How does the period change? Where is it shown in the equation?
2. Make a negative. What happens to the peaks and troughs?
3. Set h = π/2 and switch from sin to cos. What do you notice about the graph?
4. Change k. Does the period or amplitude change?
