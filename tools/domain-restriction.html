denominator (no √)

OPEN vs CLOSED?
[ ] closed bracket = value included (≥ or ≤)
( ) open paren = value excluded (> or <, and ±∞ always)

√ alone → include the boundary (radicand can be 0).
√ in denom → exclude the boundary (would make denominator 0).
