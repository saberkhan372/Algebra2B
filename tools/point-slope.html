POINT-SLOPE FORM
y − y₁ = m(x − x₁)
x₁, y₁ → a known point
m → the slope

Watch the signs: the equation uses minus signs, so the coordinates plug in with the opposite sign. If y₁ = −5, write y − (−5) = y + 5.
PARALLEL & PERPENDICULAR
Parallel: same slope.
m = 3 → parallel m = 3

Perpendicular: flip it and negate it.
m = 3/2 → perp m = −2/3

"Opposite" = sign changes.
"Reciprocal" = fraction flips.
💡 SIGN TRAP
Point (3, −5) plugs in as:
y − (−5) = m(x − 3)
y + 5 = m(x − 3) ✓

The minus before y₁ turns the negative point into a plus.
