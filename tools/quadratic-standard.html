Quadratic Standard Form
From y = ax² + bx + c to vertex, roots, and vertex form — all at once.
STANDARD FORM
y = x²
VERTEX FORM
y = x²
1 0 0
HOW TO USE
  1. Slide a, b, c to change the parabola.
  2. Watch the vertex form update instantly.
  3. Green chip = 2 real roots. Blue = 1 root. Red = imaginary roots.
  4. The orange dot is always the vertex.
KEY FORMULAS
Vertex x:   h = −b / (2a)
Vertex y:   k = c − b²/(4a)
Vertex form: y = a(x − h)² + k
Discriminant: Δ = b² − 4ac
  Δ > 0 → 2 real roots
  Δ = 0 → 1 real root (tangent)
  Δ < 0 → no real roots → imaginary solutions
               → parabola doesn't cross x-axis
👀 TRY THIS
Q1. Set a = 1, b = 4, c = 4. What's the discriminant? How many x-intercepts?
Q2. Change only c. What moves — the vertex, the shape, or both?
Q3. Find values where the parabola doesn't cross the x-axis. What does the discriminant say?
