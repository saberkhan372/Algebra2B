Exponent Rules Trainer
All five rules — product, quotient, power, zero, negative. Identify the rule, then simplify.
RULES REFERENCE ▾
PRODUCT RULE
xᵃ · xᵇ = xᵃ⁺ᵇ
Same base → add exponents
QUOTIENT RULE
xᵃ / xᵇ = xᵃ⁻ᵇ
Same base → subtract (top−bottom)
POWER RULE
(xᵃ)ᵇ = xᵃᵇ
Power of a power → multiply
ZERO EXPONENT
x⁰ = 1
Any nonzero base to the 0 = 1
NEGATIVE EXPONENT
x⁻ⁿ = 1/xⁿ

ANSWER FORMAT
Type exponents with ^:
x^7 for x⁷
1/x^3 for 1/x³
1 for zero exp.
1/16 for 2⁻⁴
WHEN TO FLIP
A negative exponent does NOT make the answer negative.

x⁻³ = 1/x³ ← positive 3 in denominator

The answer is a fraction, not a negative number.
QUOTIENT TRAP
x³/x⁷ = x^(3−7) = x⁻⁴
Don't stop there — write it as 1/x⁴.
