Function Notation Evaluator
f(x) is just a name — whatever goes in the parentheses replaces every x.
PICK A FUNCTION
PROBLEMS
f(x) IS y
f(x) is just a name for a function. It means "plug x in and get a result."

f(5) means plug 5 in for x.
f(−3) means plug −3 in for x.

Always use parentheses when substituting, especially with negatives.
⚠ SIGN TRAP
(−3)² = 9 ✓
−3² = −9 — that's different!

The parentheses matter when you square a negative.
UNDEFINED
If plugging in x makes the denominator zero, the function is undefined at that x.
(Not "no solution" — undefined.)
