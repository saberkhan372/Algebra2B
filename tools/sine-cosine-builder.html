Sine/Cosine Graph Builder
Build the wave: amplitude, period, phase shift, and midline all in one place.
y = sin(x)
amplitude = 1 period = 2π phase shift = 0 midline y = 0
Move one slider at a time. The graph labels update as the wave changes.
FUNCTION:
1 1 0 0
THE FORM
y = a · trig(b(x − h)) + k
a sets amplitude and flips the wave if negative.
b changes period: period = 2π / |b|.
h shifts the wave left or right.
k moves the midline.
KEY POINTS
pointxy

Q3. Switch sine to cosine without moving sliders. What stays the same? What changes?
