Rational Expression Builder
Build a rational function. See its graph, vertical asymptotes, and domain.
f(x) =
NUMERATOR:
x² + x +
DENOMINATOR:
x² + x +
HOW TO USE
  1. Change any coefficient.
  2. Watch the graph and info chips update.
  3. Red dashed lines = vertical asymptotes.
  4. Try making a hole (factor cancels).
👀 TRY THIS
Q1. What happens to the graph near a vertical asymptote?
Q2. Set numerator = x−2, denominator = x²−4. A hole appears — but why isn't it a VA? (Hint: factor the denominator.)
Q3. What's the domain of 1/(x−3)? Write it in interval notation.
KEY IDEAS
VA: denom = 0 (excluded x-values)
Domain: all reals except VA/holes → interval notation
Hole: factor cancels top and bottom

Horizontal asymptote — 3 cases:
Case 1: deg(top) < deg(bottom) → y = 0
Case 2: deg(top) = deg(bottom) → y = leading ratio
Case 3: deg(top) > deg(bottom) → no HA
  (if exactly 1 more → slant asymptote)
