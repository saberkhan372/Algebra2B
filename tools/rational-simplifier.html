THE PROCESS
1. Factor the numerator.
2. Factor the denominator.
3. Cancel factors that appear in both.
4. State excluded values — x-values that made the original denominator = 0.

⚠ You can only cancel factors, not terms.
First factor, then cancel.
USEFUL PATTERNS
Difference of squares:
x²−a² = (x−a)(x+a)

Perfect square tri.:
x²−2ax+a² = (x−a)²

Factor out GCF first:
3x²+6x = 3x(x+2)
