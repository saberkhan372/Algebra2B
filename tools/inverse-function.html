HOW TO FIND f⁻¹: swap x ↔ y, solve for y
KEY IDEA
If (a, b) is on f,
then (b, a) is on f⁻¹.

The graphs are mirror images over y = x.

f has an inverse only if it is one-to-one — the Horizontal Line Test passes.
