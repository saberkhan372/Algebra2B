THE INVERSE CONNECTION
To find the inverse of any function: swap x and y.
If (a, b) is on y = bˣ, then (b, a) is on y = logb(x).
Swapping coordinates = reflecting over y = x.
Proof with b = 2:
(3, 8) is on y = 2ˣ because 2³ = 8.
(8, 3) is on y = log₂(x) because log₂(8) = 3. ✓
EVERYTHING SWAPS
domain (−∞, ∞) ⟷ range (−∞, ∞)
range (0, ∞) ⟷ domain (0, ∞)
y-intercept (0, 1) ⟷ x-intercept (1, 0)
horiz. asymp. y = 0 ⟷ vert. asymp. x = 0
Every property of one is the "swapped" version of the other.
