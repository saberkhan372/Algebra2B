WHY VERIFY?
A solution is any point on the line — there are infinitely many. After solving a system, always plug the point into both original equations to confirm it satisfies both. "You can always, always, always check."

SLOPE = RISE / RUN
Steep stairs → big slope.
Gentle stairs → small slope.
Downhill (right) → negative.
Flat → slope = 0.
Vertical wall → undefined.
