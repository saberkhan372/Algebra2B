HOW TO USE
  1. Pick Long or Synthetic mode.
  2. Answer each step in order.
  3. Hit Enter or "check".
  4. Use "hint" if stuck.
LONG DIVISION
① Divide front terms
② Multiply by divisor
③ Subtract — ⚠️ flip signs!
④ Bring down, repeat
Remainder ≠ 0 → not a factor.
SYNTHETIC DIVISION
① Divisor must be linear
② Set divisor = 0 → box #
③ Write coefficients (0 for gaps)
④ Bring down · multiply · add
Last number = remainder. Quotient is one degree lower.
LONG VS SYNTHETIC?
Use synthetic only when the divisor is linear (degree 1). For quadratic or higher divisors, use long division. Both give the same answer.
