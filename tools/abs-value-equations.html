Absolute Value Equation Stepper
Isolate first. Then split into two branches. Then check both.
PICK A PROBLEM
THE PROCESS
1. Isolate the absolute value bars first.
2. Split into 2 branches:
  |stuff| = k
  ↙     ↘
  stuff = k    stuff = −k
3. Solve each branch.
4. Check both answers.
⚠ NEVER DO THIS
You cannot distribute into absolute value bars:
2|x − 3| ≠ |2x − 6|

The bars must stay together until they're isolated.
NO SOLUTION?
If the isolated right side is negative, stop immediately.

Absolute value = distance from zero. Distance is never negative. No solution.
