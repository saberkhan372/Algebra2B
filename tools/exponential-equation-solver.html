Exponential Equation Solver
Decide first: same base, log both sides, or use ln for e.
PROBLEM:
SOLVE FOR x:
same base?Rewrite both sides, then set exponents equal.
no match?Log both sides and bring the exponent down.
base e?Use ln so e and ln undo each other.
FINAL ANSWER
HOW TO USE
  1. Pick a problem.
  2. Answer one move at a time.
  3. Use exact log form before decimals.
  4. Round only at the end.
THE MOVES
2^x = 16 becomes 2^x = 2^4, so x = 4.

3^x = 20 becomes x log(3) = log(20), so x = log(20)/log(3).

e^(2x) = 10 becomes 2x = ln(10).
WATCH FOR
If there is a coefficient in front, divide it away before logging. If the problem is a word model, isolate the exponential part first.
