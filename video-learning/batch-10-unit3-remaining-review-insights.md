## U3-D2: Intercept Form and Quadratic Forms

Classroom flow:
- The teacher connects all three quadratic forms:
  - vertex form gives `h, k`;
  - standard form is hardest to graph directly;
  - intercept form gives zeros/x-intercepts/solutions.
- `zeros`, `solutions`, `roots`, and `x-intercepts` are treated as interchangeable vocabulary.
- In intercept form, set each factor equal to zero.
- The vertex is centered between the two intercepts:
  - add the intercepts and divide by 2;
  - plug that x-value into any equivalent form to get y.
- If both factors are the same, there is one x-intercept and the vertex sits on the x-axis.
- If there are no real intercepts, the solutions are imaginary.
- The leading coefficient can be factored out before using intercept form; it is not itself an x-intercept.

Tool implications:
- Quadratic Standard Form should keep the three-form map visible: standard, vertex, intercept.
- Quadratic tools should label `zero = solution = root = x-intercept`.
- Intercept-form prompts should ask students to find the midpoint of two roots, then plug in for the vertex.
- When there is only one repeated root, the tool should name it as both a double root and the vertex x-value.

## U3-D4: Quadratic Word Problems and Projectiles

Classroom flow:
- Word problems are framed as "underneath the words are regular math problems."
- Quadratic means parabola; projectile context maps directly:
  - initial time is `t = 0`;
  - initial height is the constant term;
  - ground means height `0`;
  - maximum/minimum is the vertex.
- When a problem gives a height/viscosity/value and asks for time/input:
  - set the function equal to that value;
  - move everything to one side;
  - solve the resulting quadratic.
- If the target height is below the vertex, two times can be valid: one on the way up, one on the way down.
- Vertex workflow is repeated:
  - use `-b/(2a)` for the input/time;
  - plug it back in for the height/output.
- Domain/range in projectile context is physical:
  - time starts at `0` and ends when the object hits the ground;
  - range runs from ground level to maximum height.
- Negative velocity means downward motion; velocity at the top is zero.

Tool implications:
- Quadratic Standard Form should have a "word problem interpreter" mode with cards for:
  - plug in time/input;
  - set output equal to a target;
  - find vertex time;
  - find max/min output.
- Projectile problems should draw horizontal target-height lines and show why two times may appear.
- Exact/calculator output should keep units attached and round only at the final interpretation step.

## U3-D7: Rational Simplifying and Denominator Cleanup

Classroom flow:
- Rational expression simplification repeats the original-domain rule:
  - factor first;
  - cancel common factors;
  - excluded values come from the original denominator, even canceled factors.
- `x` alone in the denominator is a factor, so `x = 0` is an excluded value.
- Square roots cannot remain in the denominator.
- `i` cannot remain in the denominator.
- If the denominator is a single radical, multiply top and bottom by that radical.
- If a radical denominator can simplify first, simplify before rationalizing.

Tool implications:
- Rational Simplifier should keep an "original denominator" panel visible after cancellation.
- Add denominator-cleanup cards:
  - single radical denominator;
  - single `i` denominator;
  - simplify radical first, then rationalize.

## U3-D8: Powers of i and Conjugates

Classroom flow:
- The core power cycle is:
  - `i = i`;
  - `i^2 = -1`;
  - `i^3 = -i`;
  - `i^4 = 1`.
- Everything after that repeats by groups of four.
- Students may divide the exponent by 4, but they must show what the remainder means:
  - whole number remainder 0 -> `1`;
  - `.25` or remainder 1 -> `i`;
  - `.5` or remainder 2 -> `-1`;
  - `.75` or remainder 3 -> `-i`.
- Conjugates are introduced by `a + b` / `a - b`: outer and inner terms cancel.
- Complex conjugates remove `i` from a denominator.
- Radical conjugates remove a binomial radical denominator.
- Multiplying by a conjugate is framed as multiplying by 1 because the same expression is used on top and bottom.

Tool implications:
- Imaginary Number Sandbox should add a powers-of-i cycle practice strip.
- Conjugate/rationalizing practice should distinguish:
  - one-term denominator: multiply by that radical or `i`;
  - two-term denominator: multiply by the conjugate.
- Feedback should require students to show the remainder, not just the final cycle value.

## U3-D9: Literal Equations and Building Quadratic Forms

Classroom flow:
- Literal equations are "equations with other variables than just x."
- The first move is to identify the target variable.
- If the target is in a denominator, multiply by the whole denominator.
- If the target appears in multiple terms:
  - move target terms to one side;
  - move non-target terms to the other side;
  - factor out the target variable;
  - divide by the remaining group.
- Completing the square with letters is used to derive the quadratic formula, showing why the formula exists.
- Vertex-form equation building:
  - plug known vertex into `h, k`;
  - plug a known point into `x, y`;
  - solve for `a`.
- Intercept-form equation building:
  - plug zeros into `x1, x2`;
  - plug a known point into `x, y`;
  - solve for `a`.

Tool implications:
- A Literal Equation Isolator would be useful as a compact algebra tool.
- Quadratic Standard Form or Complete the Square Trainer should include a "where did the quadratic formula come from?" reveal using completing the square.
- Quadratic form-builder prompts should ask students to solve for `a` from vertex+point or zeros+point.

## U3-D10 and Test Review: Mixed Graphing, Piecewise, and Cumulative Skills

Classroom flow:
- Piecewise graphs now include parabolas and absolute value functions.
- Boundary first:
  - draw the dividing line;
  - decide which rule lives on each side;
  - use open/closed endpoints from the inequality.
- Parabola vertex may be outside the active interval.
  - If visible, use the vertex and nearby points.
  - If not visible, plug in boundary and nearby x-values.
- Absolute value pieces use vertex plus slope.
- Parabola pieces use vertex plus the `a, 4a` pattern when helpful.
- Test review is cumulative:
  - systems;
  - piecewise evaluation/graphing;
  - point-slope form;
  - inequalities and sign flips;
  - negative exponents;
  - vertex, standard, and intercept forms;
  - factoring and special products;
  - rational expressions and excluded values;
  - radicals/complex numbers;
  - quadratic formula;
  - completing the square;
  - projectile word problems;
  - literal equations;
  - transformations.

Tool implications:
- Piecewise Function Grapher needs a parabola-piece mode and a "vertex outside active interval" warning.
- Review tools should intentionally mix Unit 1/2 skills with Unit 3 skills.
- Quadratic tools should keep form choice visible: vertex form for graphing, intercept form for zeros, standard form for formula/discriminant.

## Cross-Cutting Design Patterns

- Use vocabulary bridges everywhere: `zeros = roots = solutions = x-intercepts`.
- Make the student's first decision explicit:
  - graphing from intercept form -> find zeros first;
  - word problem asks "when" -> set output equal to target;
  - literal equation -> identify target variable;
  - piecewise graph -> draw boundary first.
- Preserve the teacher's repeated warnings:
  - excluded values come from the original denominator;
  - you cannot leave a square root or `i` in the denominator;
  - if the target variable appears twice, factor it out;
  - physical domains reject negative time.
- Unit 3 is a form-switching unit: tools should help students choose the form before doing algebra.
