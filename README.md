# Algebra 2B Playgrounds

A static Algebra 2 intuition site with interactive classroom tools, unit pages, planning notes, and video-derived curriculum insights.

## Local Preview

```bash
python3 -m http.server 8091
```

Then open `http://127.0.0.1:8091/`.

## GitHub Pages

This repo is designed to be served directly from GitHub Pages. The entry point is `index.html`.

## Included

- Static site pages: `index.html`, `u1.html` through `u7.html`, `about.html`, and `styles.css`
- Interactive tools in `tools/`
- Claude wireframe/project artifacts in `algebra-2-tools/`
- Video-learning transcripts, synthesis notes, PDF text extracts, and contact sheets in `video-learning/`
- Build/project planning in `PLAN.md`

## Excluded

- Raw classroom videos in `teacher and student work/`
- Local Whisper runtime/model cache in `video-learning/.venv/` and `video-learning/models/`
