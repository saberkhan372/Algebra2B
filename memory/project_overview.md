**Algebra 2B Playgrounds** is a static site (GitHub Pages) at `Algebra2B/`. Serves as classroom supplement for 7-unit Algebra 2 course (Sept–May).

**Site structure:**
- `index.html` — homepage with 29-tool grid, search/filter, animated TOTW canvas
- `about.html` — teacher letter, FAQ, credits
- `u1.html`–`u7.html` — unit pages (lesson stacks with tool links)
- `tools/` — 29 standalone interactive HTML tools
- `styles.css` — all shared CSS variables and classes
- `algebra-2-tools/` — Claude Design wireframe exports (reference only)
- `video-learning/` — transcripts, batch insight notes, contact sheets, PDF extracts

**29 tools currently built (as of 2026-05-27):**
U1: Quadratic Slider, Substitution Stepper, Elimination Race, Factoring Lab, Piecewise Grapher
U2: Abs Value Grapher, Transformations Explorer, Neg Exponent Flipper, Diff of Squares, Diff of Cubes
U3: Imaginary Sandbox, Quadratic Standard Form, Rational Expression Builder, Complete the Square
U4: Rational Exponents Tower, Cubic & Radical Grapher, Composition Machine, Inverse Function Revealer
U5: Log↔Exp Converter, Exponential Explorer, Log Properties Sandbox, Exponential Equation Solver
U6: Rational Simplifier, Adding Rationals, Polynomial Sketch Pad, Polynomial Division Stepper
U7: SOH CAH TOA Solver, Unit Circle Walker, Sine/Cosine Graph Builder

**1 tool still planned (coming-soon on unit page):**
U5 D3: Exponential Model Builder (keyword classifier, formula-slot drag, compound/continuous/simple)

**PLAN.md tracks all build phases** — see it for priority order, who builds what, and design constraints.

**Why:** Classroom supplement giving students visual/interactive exposure to concepts. No logins, no tracking, no cost.

**How to apply:** Always check PLAN.md for current priorities and constraints before suggesting or building new tools.
