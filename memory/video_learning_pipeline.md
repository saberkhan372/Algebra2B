**video-learning/** is the curriculum research workspace. Contains:
- `video_inventory.csv` — full local video inventory (unit/day, duration, size, path)
- `transcripts/` — 75+ Whisper transcripts of classroom lessons (batch-11 transcription pass added 46 more; 29 complete as of 2026-05-30)
- `pdf-text/` — extracted text from key lesson PDFs (U4 radicals/exponents, U5 radical equations)
- `contact-sheets/` — visual contact sheets matching transcript moments to board/calculator work
- `U2-D4-negative-exponents-notes.md` — first pilot notes
- `batch-1` through `batch-12` insight files — synthesized tool-improvement ideas per unit cluster

**Batch coverage:**
- batch-1: abs value, factoring, neg exponents, imaginary numbers, rational expressions
- batch-2: substitution/elimination, quadratic graphing, completing the square, special factoring
- batch-3: radical graphing, rational exponents, radical equations, rational simplification
- batch-4: exponential/log, rational-function graphing, composition, polynomial sketching, right-triangle trig
- batch-5: exponential models, log graphing/solving, polynomial roots, long/synthetic division
- batch-6: angle/radian, periodic functions, sine/cosine, probability, statistics
- batch-7: rational expression operations (multiply/divide/add/subtract/solve), Unit 8 study guide
- batch-8: Unit 2 functions, domain/range, calculator workflow, transformations, test review
- batch-9: 25-26 revisit of U1/U2/U3 foundations — h-opposite explanation, three-form quadratic, GCF-first principle
- batch-10: Unit 3 remaining — intercept form, word problems, powers of i, conjugates, literal equations, piecewise parabolas
- batch-11: cross-site audit — linked orphaned tools, improved Adding Rationals, Abs Value Grapher h-tooltip; built Literal Equations, Domain Restriction Sorter, Coterminal & Radians
- batch-12: U1 (25-26) full analysis — slope, piecewise plug-boundary technique, inequalities flip rule, abs value two-branch, function notation; built Inequality Solver, Abs Value Equation Stepper, Point-Slope Trainer, Function Notation Evaluator
